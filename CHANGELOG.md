# Release Notes

## [Unreleased](https://github.com/Pushctl/Pushctl-Laravel-SDK/compare/v0.2.0...master)

## [v0.2.0](https://github.com/Pushctl/Pushctl-Laravel-SDK/releases/tag/v0.2.0) - 2026-08-14

- Add a Laravel notification channel for sending visible and data-only Pushctl notifications.
- Add fluent message options for delivery, platform-specific payloads, and idempotency.
- Add direct notification sending through the container-bound client and facade.
- Add publishable configuration and support for Laravel 12 and 13 on PHP 8.3 through 8.5.
- Publish the package as `pushctl/pushctl-laravel` under the `Pushctl\PushctlLaravel` namespace.
